# Références visuelles

## Source produit

Le système est dérivé du parcours Taxi public existant dans
`artifacts/maximus/src/pages/public-shop.tsx`. Les couleurs de repli visibles
sont le bleu nuit `#161d27`, l’ambre `#f2b705`, le fond chaud `#f2f3ef` et la
bordure `#d9dcd6`. Les couleurs configurées par entreprise restent dynamiques
dans l’application.

La typographie MAXIMUS existante fournit DM Sans pour l’interface et Space Mono
pour les métriques. Les tokens sont définis dans `tokens.json`.
