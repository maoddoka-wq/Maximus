---
name: Navigation mobile MAXIMUS
description: Règles de lisibilité du menu mobile de l’espace entreprise.
---

Sur mobile, le menu de l’espace entreprise doit séparer l’administration des modules et replier les sections de modules non actives. La section correspondant à la page courante reste ouverte automatiquement.

**Why:** Afficher toutes les fonctionnalités de plusieurs modules dans un tiroir étroit rend la navigation longue, bruyante et difficile à parcourir.

**How to apply:** Conserver les fonctionnalités regroupées par module, afficher un compteur de fonctionnalités dans l’en-tête de section, garder l’identité de l’entreprise visible dans un en-tête fixe et fermer le tiroir après une navigation.
