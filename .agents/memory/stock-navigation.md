---
name: Navigation Gestion de stock
description: Règle confirmée pour la structure et l’orientation du menu interne du module de stock.
---

Gestion de stock doit contenir exactement, dans cet ordre : Tableau de bord, Articles, Entrées de stock, Sorties de stock, Demandes, Inventaire, Rapports, Référentiels, Utilisateurs et Paramètres. Dans l’espace entreprise, ces rubriques suivent le mode choisi : menu principal par défaut, ou barre horizontale sans duplication dans le menu si ce mode a été sélectionné.

**Why:** L’utilisateur a fixé la liste des dix rubriques, refusé une navigation horizontale imposée, puis demandé que le mode soit configurable par entreprise.

**How to apply:** Toute évolution de Gestion de stock doit réutiliser ces dix rubriques sans en ajouter, en supprimer ou en réordonner. Respecter [la politique de choix de navigation](company-navigation-policy.md), y compris sur les petits écrans.

Les rôles peuvent toutefois masquer certaines de ces rubriques et limiter leurs actions via les permissions propres à chaque sous-fonction ; cela ne change pas la liste de référence.
