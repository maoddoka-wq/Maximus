---
name: Navigation Gestion de stock
description: Règle confirmée pour la structure et l’orientation du menu interne du module de stock.
---

Gestion de stock doit contenir exactement, dans cet ordre : Tableau de bord, Articles, Entrées de stock, Sorties de stock, Demandes, Inventaire, Rapports, Référentiels, Utilisateurs et Paramètres. Dans l’espace entreprise, ces rubriques doivent apparaître uniquement dans le menu principal, sans barre horizontale supplémentaire dans la page.

**Why:** L’utilisateur a fixé la liste des dix rubriques, puis a corrigé l’ajout d’une navigation horizontale dans l’espace entreprise : les fonctionnalités doivent être seulement dans le menu. Cette correction remplace l’ancienne consigne d’orientation horizontale pour cet espace.

**How to apply:** Toute évolution de Gestion de stock doit réutiliser ces dix rubriques sans en ajouter, en supprimer ou en réordonner. La navigation de l’espace entreprise passe par son menu existant, y compris sur les petits écrans.

Les rôles peuvent toutefois masquer certaines de ces rubriques et limiter leurs actions via les permissions propres à chaque sous-fonction ; cela ne change pas la liste de référence.
