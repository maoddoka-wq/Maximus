---
name: Entreprises sans employés
description: Décision produit pour les entreprises e-commerce ou autres activités gérées directement par leur administrateur.
---

Une entreprise choisit entre deux modes dans MAXIMUS : « mode seul », où l’administrateur travaille directement dans les modules activés, et « mode avec équipe », où l’espace Organisation permet de structurer la Direction technique, les rôles et les employés. Le mode seul masque l’espace Organisation & accès, mais ne supprime jamais les employés déjà enregistrés.

**Pourquoi:** certaines boutiques e-commerce n’ont pas d’équipe salariée et ne doivent pas être contraintes de créer une hiérarchie ou des comptes employés.

**Comment appliquer:** le mode seul doit rester disponible pour les boutiques e-commerce sans équipe, tandis que le mode avec équipe doit être activé explicitement quand l’entreprise veut structurer ses opérations. Toute future fonctionnalité dépendant des employés doit respecter le mode choisi au lieu de créer implicitement une organisation.
