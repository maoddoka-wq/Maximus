---
name: Application chauffeur Android partagée
description: Décision produit pour l’installation Android et l’identification des entreprises dans MAXIMUS Chauffeur.
---

Garder une seule application MAXIMUS Chauffeur pour toutes les entreprises. Le code de connexion entreprise sert à sélectionner le tenant; ne générer ni APK ni identifiant de paquet par entreprise. Le QR commun installe l’application, puis l’utilisateur saisit le code de son entreprise à la connexion.

**Why:** L’utilisateur a explicitement remplacé l’idée d’un APK par société par une application partagée identifiée par le code entreprise.

**How to apply:** Publier une version signée par version de l’application, conserver un seul lien d’installation stable et ne jamais placer d’identifiants chauffeur dans le QR. Toute identité visuelle propre à une entreprise doit être appliquée à l’exécution, après identification.
